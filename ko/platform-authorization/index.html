Hubitos 타사 플랫폼 연결 권한 안내

이 안내는 Hubitos가 타사 계정에 연결하는 방식, 연결 권한으로 허용되는 범위, 권한을 철회하는 방법을 설명합니다. 개인정보처리방침 및 서비스 약관과 함께 읽어 주세요. 문의: support@hubitos.ai.

최종 업데이트: 2026년 10월 4일 · 시행일: 2026년 10월 10일

1. 연결할 서비스는 사용자가 선택합니다

요청한 기능에 필요한 경우를 제외하면 외부 서비스 연결은 선택 사항입니다. Hubitos 로그인, 소셜 계정 연결, 메시징 봇 연결, 상점 연결 승인은 각각 별개의 작업입니다. 하나를 승인해도 나머지가 자동으로 승인되지는 않습니다.

연결을 승인하기 전에 권한 승인 화면에 표시된 제공업체, 애플리케이션 이름, 계정 또는 페이지, 요청 권한을 확인하세요. 권한을 개별적으로 선택할 수 있는 경우 작업에 필요한 권한을 선택하세요. 권한을 거부하면 관련 기능을 사용할 수 없을 수 있습니다. 타사 비밀번호, 인증 코드, 액세스 토큰을 Hubitos 지원팀에 제공하지 마세요.

2. 지원하는 연결 유형

지원 여부는 출시 버전, 지역, 설정, 플랫폼에서 승인한 권한에 따라 다릅니다. 아래 표는 연결 목적을 설명하며, 나열된 모든 기능에 대한 접근을 보장하지 않습니다.

연결 유형관련 정보 또는 권한목적과 범위
X계정 식별 정보, 승인된 읽기·쓰기 권한, 미디어 업로드 권한, 허용된 경우 지속적인 연결 권한계정을 표시하고, 사용자가 승인한 게시물을 준비하거나 게시하며, 허용된 정보를 조회하고 요청한 연결을 유지합니다. X 게시 연결은 tweet.read, tweet.write, users.read, offline.access, media.write를 요청하며, 실제 범위는 권한 승인 시 표시되는 허용 내역에 따릅니다.
Facebook 페이지승인된 계정 식별 정보, 선택한 페이지, 페이지 게시 권한, 허용된 지표선택한 페이지에 게시하고 허용된 결과를 표시합니다. 페이지를 연결해도 개인 Facebook 데이터에 제한 없이 접근할 수 있는 것은 아닙니다.
Instagram승인된 프로필·계정 식별자, 콘텐츠 게시 권한, 허용된 계정 또는 콘텐츠 정보플랫폼에서 지원하는 계정 유형과 권한 범위 내에서 승인된 Instagram 콘텐츠 및 관련 상태나 지표를 관리합니다.
Threads승인된 계정 식별자, 콘텐츠 및 게시 권한, 허용된 지표사용자가 승인한 Threads 콘텐츠를 관리하고 게시합니다.
TikTok승인된 프로필 정보, 동영상, 통계, 게시 권한 및 설정계정을 식별하고, 허용된 콘텐츠를 분석하며, 승인된 게시물을 제출합니다. TikTok은 콘텐츠를 검토·거부·삭제하거나 제한할 수 있습니다.
YouTube승인된 채널 식별자, 업로드 권한, 동영상 메타데이터, 허용된 지표YouTube API Services를 통해 선택한 채널에 게시하고 허용된 상태와 정보를 표시합니다. 이 권한으로 Gmail이나 Google Drive에 접근할 수 있는 것은 아닙니다.
LinkedIn승인된 회원 또는 조직 식별 정보와 실제로 부여된 게시·보고 권한지원하는 대상에 승인된 콘텐츠를 게시하고 허용된 결과를 표시합니다.
Google 또는 Zalo 로그인제공업체 식별자 및 제공된 경우 이메일 등 로그인 과정에서 반환되는 식별·프로필 정보Hubitos 계정을 인증하거나 연결합니다. 로그인 승인만으로 게시 권한이 부여되지는 않습니다.
Telegram 또는 Zalo 봇(지원되는 경우)연결된 메시징 계정 식별자, 봇에 보낸 메시지·첨부파일, 전송 정보연결된 봇을 통해 사용자의 지시를 받고 결과를 전달합니다.
TikTok Shop(지원되는 경우)판매자가 승인한 상점 식별자, 상점 상세 정보, 허용된 권한 범위 및 인증 정보별도의 상점 연결을 설정합니다. 상품·주문·고객 데이터 관련 기능에는 해당 기능의 구현과 관련 고지가 필요하며, 연결 자체가 모든 상점 기능이 구현되었다는 의미는 아닙니다.

3. 직접 연결과 통합 제공업체

Hubitos는 X에 별도의 OAuth 절차를 사용합니다. Instagram, Facebook 페이지, TikTok, YouTube, Threads, LinkedIn의 소셜 센터 연결 절차는 권한 승인과 게시를 지원하기 위해 Upload-Post를 사용합니다. 따라서 권한 승인 화면이나 플랫폼의 연결된 앱 설정에 Upload-Post 또는 해당 애플리케이션 식별 정보가 표시될 수 있습니다.

Upload-Post와 게시 대상 플랫폼은 연결에 필요한 권한 정보, 계정·채널 식별자, 제출한 콘텐츠, 게시 설정, 상태, 허용된 지표를 받거나 유지할 수 있습니다. Upload-Post 개인정보처리방침을 확인하세요. 제공업체가 관리하는 연결이라고 해서 Hubitos가 모든 플랫폼의 액세스 토큰을 직접 저장하는 것은 아닙니다.

이러한 관리형 연결의 권한은 승인 절차와 플랫폼 설정에 따라 정해집니다. 확인되지 않은 고정 권한 목록을 모든 사용자에게 실제로 부여되는 권한인 것처럼 제시하지 않습니다. 선택한 기능과 무관한 권한 요청으로 보이면 support@hubitos.ai로 문의하세요.

4. TikTok 관련 권한 승인

Hubitos는 직접 또는 실제 활성화된 연동을 통해 TikTok Login Kit, Display API, Content Posting API를 지원할 수 있습니다. TikTok 연결은 사용자가 승인한 접근만 허용합니다. 이는 TikTok이 Hubitos를 보증한다는 의미가 아니며, 비공개 TikTok 데이터에 제한 없이 접근할 수 있는 권한을 부여하지도 않습니다.

미디어, 캡션, 해시태그, 공개 대상과 개인정보 설정, 상호작용 설정, 필요한 상업적 콘텐츠 또는 AI 콘텐츠 고지에 대한 책임은 사용자에게 있습니다. Hubitos는 사용자가 승인한 예약 작업을 포함하여 사용자의 요청이나 확인이 있을 때만 게시를 시작하며, TikTok이 요구하는 추가적인 작업별 확인 절차를 준수해야 합니다.

TikTok의 관련 서비스 약관, 개인정보처리방침, 커뮤니티 가이드라인 및 개발자 규칙을 준수해야 합니다. 콘텐츠의 수락, 게시, 추천 또는 유지 여부는 TikTok이 결정합니다. Hubitos는 독립적인 서비스이며 TikTok이 소유, 후원, 보증 또는 운영하지 않습니다.

TikTok Shop 판매자 권한 승인은 TikTok 소셜 계정 권한 승인과 별개입니다. TikTok Shop이 표시하는 선택된 상점과 권한 범위를 별도로 확인하세요.

5. 권한 승인 후의 작업

권한 승인은 허용된 연결을 활성화하며 가능한 모든 작업을 일괄 승인하는 것은 아닙니다. 게시와 자동화는 사용자가 승인한 콘텐츠, 대상, 지시에 따라 작동합니다. 예약 작업은 나중에 실행될 수 있으며, 백그라운드 동기화는 기능 유지에 필요한 허용된 정보를 조회할 수 있습니다. 일부 권한에는 갱신 접근 권한이 포함되므로 작업마다 다시 연결할 필요가 없습니다.

제출하기 전에 확인 화면을 검토하세요. 지시가 바뀌면 향후 예약 작업을 중지하거나 수정하세요. 플랫폼으로 보낸 콘텐츠에는 해당 플랫폼의 처리 방식과 공개 설정이 적용됩니다.

6. 연결 해제 및 접근 권한 철회

  • Hubitos에서 해당 계정 관리 또는 권한 설정을 열고 연결을 선택한 후, 제공되는 연결 해제 또는 권한 철회 작업을 선택하세요.
  • 확인 내용을 주의 깊게 검토하세요. 대기 중인 콘텐츠 정리 기능을 제공하는 버전에서는 화면에 설명된 대로 초안 대상과 예약 게시물에 영향을 줄 수 있습니다. 이 동작이 모든 과거 기록의 삭제를 보장하는 것은 아닙니다.
  • 플랫폼의 연결된 앱 설정에서도 권한을 철회할 수 있습니다. Google과 YouTube의 경우 Google 보안 설정을 이용하세요. 제공업체 관리형 연결은 실제 권한 승인에 사용된 애플리케이션 식별 정보를 확인하세요.
  • 연결 해제에 실패하거나 이미 게시가 진행 중이면 support@hubitos.ai로 문의하세요. 권한을 철회해도 플랫폼에 이미 제출된 콘텐츠를 회수하지 못할 수 있습니다.

Hubitos가 보유한 인증 정보를 제거하는 것과 플랫폼에서 권한을 철회하는 것은 별개의 작업입니다. 접근 권한 철회는 효력이 발생하는 시점에 해당 권한의 사용을 중단하지만, 그 자체로 Hubitos 또는 플랫폼에 이미 저장된 모든 데이터를 삭제하지는 않습니다. 삭제 요청에는 데이터 삭제 안내를 이용하세요. Hubitos를 제거해도 모든 권한이 철회되거나 서버 측 예약 작업이 취소되는 것은 아닙니다.

7. Google 및 YouTube 관련 조건

YouTube 기능은 YouTube API Services를 사용합니다. 해당 기능을 사용하면 YouTube 서비스 약관에 동의하는 것입니다. Google의 정보 처리 방식은 Google 개인정보처리방침에 설명되어 있습니다.

Hubitos의 Google API 정보 사용 및 전송은 제한된 사용 요건을 포함한 Google API Services 사용자 데이터 정책을 준수합니다. 중개업체가 연결을 지원하는 경우에도 플랫폼 데이터에 대한 제한은 계속 적용됩니다.

8. 도움 및 개인정보 관련 요청

권한 문의, 연결 실패, 권한 철회 지원, 삭제 요청은 Hubitos 계정 이메일과 관련 제공업체 및 계정 식별자를 포함하여 support@hubitos.ai로 보내 주세요. 비밀번호나 토큰은 포함하지 마세요. 연결을 변경하거나 계정 데이터를 공개 또는 삭제하기 전에 요청에 비례하는 확인을 요구할 수 있습니다.
