Hubitos 隱私權政策

本政策說明 Hubitos 可能收集哪些資料、收集目的、如何使用 Meta、TikTok 及其他已連線平台的資料，以及使用者如何撤銷存取權限或請求刪除資料。本政策適用於 Hubitos 網站、網頁應用、桌面應用及相關服務。在本政策中，“Hubitos”“我們”指 Hubitos 服務提供方。聯絡方式：support@hubitos.ai。

我們收集的資料

Hubitos 僅收集執行工作臺及已連線的發布工作流所需的資訊。

  • 帳號資訊，例如姓名、電子郵件地址、使用者標識和工作臺偏好設定。
  • 使用者提供的內容，例如提示詞、貼文草稿、文案、上傳的附件、生成的檔案及工作流配置。
  • 已連線服務的授權後設資料，包括服務商名稱、授予的權限範圍、已連線帳號標識和令牌狀態。
  • 基本產品使用和診斷資訊，例如功能事件、錯誤日誌、裝置或瀏覽器資訊及應用版本。

根據您使用的功能，這些類別還包括：

  • 登入及帳號安全資訊，例如電子郵件地址或電話號碼、密碼認證記錄、驗證事件、登入會話，以及登入服務商返回的標識。使用 Google 或其他服務商登入，本身並不授權社交發布或存取無關的帳號資料。
  • 已連線社交帳號的資訊，例如帳號和頻道標識、顯示名稱、頭像、Facebook 公共主頁、已授予權限、連線狀態、貼文、發布回執，以及獲准的互動或表現資訊。
  • 內容及工作上下文，包括對話、檔案、圖片、影片、商品參考資料、社群分析輸入、草稿和定時貼文、任務結果，以及在可用並啟用的情況下，為後續工作提供個性化體驗而儲存的 AI 記憶和偏好。
  • 計費和交易資訊，例如方案、積分餘額、用量、訂單和支付參考編號、支付狀態及訂閱狀態。支付卡詳細資訊由支付服務商透過其支付介面處理；Hubitos 接收管理您的購買所必需的交易資訊。
  • 您主動透過已連線的訊息機器人傳送的資訊，包括關聯帳號標識、訊息、附件及投遞資訊。連線機器人並不授予對您所有私人對話的普遍存取權限。
  • 您要求我們分析的公開帳號、貼文或商品頁面的資訊，這些資訊從相關平台或資料獲取服務取得。公開來源分析與私人帳號授權是不同的活動；二者均不授予對平台非公開資料的不受限制的存取權限。

我們收集資料的原因

資料用於提供 Hubitos 功能、保護使用者會話及提供支援。

  • 建立、儲存、重新開啟和同步對話、工作流、工具包、生成檔案及使用者偏好。
  • 處理使用者指令和附件，使 AI 助手能夠起草、總結、轉換和組織使用者請求的工作。
  • 驗證使用者身份、防止濫用、調查錯誤並維持可靠的服務執行。
  • 回應支援請求、排查使用者報告的問題，以及傳達重要的產品或政策更新。

Threads、Facebook 和 Instagram 授權資料的使用

使用者連線 Meta 旗下服務時，Hubitos 僅將授予的權限用於使用者指示的工作臺和發布操作。

  • Hubitos 僅請求使用者所選功能必需的權限，例如識別已連線帳號，或準備和發布經使用者批准的內容。
  • 授權資料可用於展示已連線帳號狀態、起草或發布內容、讀取獲准的發布後設資料，以及維持使用者請求的工作流連線。
  • Hubitos 不出售 Meta 授權資料，也不與第三方共享該資料，營運產品所必需的服務提供商或法律要求的情形除外。

TikTok 授權及內容資料的使用

在可用的情況下，Hubitos 可能直接或透過支援連線的服務提供商，使用 TikTok 開發者產品提供帳號連線、內容分析和發布功能，包括 Login Kit、Display API 和 Content Posting API。您可使用的產品和權限取決於實際啟用的整合及您批准的授權頁面。

  • 我們使用獲准的個人資料、帳號標識、統計資訊和影片，識別您連線的帳號，並提供您請求的分析、內容管理和發布功能。
  • 我們僅為您請求或確認的發布操作向 TikTok 提交內容，包括您已批准的定時操作。您可控制內容，以及該操作介面提供的受眾、隱私、互動和披露設定。
  • 連線帳號並不意味著允許發布任意內容、存取私信或使用無關的 TikTok 資料。
  • TikTok 可能按照其自身條款和隱私權政策處理提交的內容及相關後設資料。斷開 Hubitos 連線不會移除 TikTok 已持有的影片或貼文。
  • 您可透過 Hubitos 提供的連線管理功能或 TikTok 的已連線應用設定撤銷存取權限，並可聯絡 support@hubitos.ai 請求刪除 Hubitos 持有的資料。

TikTok Shop 採用獨立的賣家授權。如提供該功能且您已連線，它可能提供專門啟用的店鋪功能所需的店鋪標識、店鋪詳情、授權範圍及憑據。TikTok 社交帳號連線不會授權存取 TikTok Shop。任何額外的商品、訂單或客戶資料處理，都必須在相關店鋪功能使用前作出披露。

Google 和 YouTube 資料

當您使用 YouTube 連線時，Hubitos 使用 YouTube API 服務，包括透過其發布整合服務商，管理您授權的頻道及發布操作。相關資訊可能包括頻道標識、個人資料、上傳後設資料、發布狀態及獲准的表現資訊。

Google 登入和 YouTube 頻道授權有不同的用途。除非某項獨立功能請求相關存取且您予以授權，否則二者均不授予 Gmail、Google Drive 或其他 Google 產品的存取權限。

Hubitos 對從 Google API 收到的資訊的使用和傳輸，將遵守 Google API 服務使用者資料政策，包括其中的有限使用要求。該資訊用於已披露的、面向使用者的功能，不用於廣告定向，也不用於開發或訓練通用 AI 模型。任何獲准的 AI 處理仍限於已授權的功能及適用的平台要求。

Google 的處理活動也適用 Google 隱私權政策。您可以透過 Google 安全設定撤銷存取權限。向 Hubitos 請求刪除資料的方式見下文及資料刪除說明。

存取令牌處理

存取令牌被視為敏感憑據。

  • Hubitos 僅在維持使用者授權的連線或完成使用者請求的工作流所需時，才可能儲存存取令牌。
  • 儲存的令牌使用合理的技術控制措施保護，不會公開在網頁、面向使用者的日誌或營銷材料中。
  • 令牌僅在已授權連線或請求操作所需的期間保留。根據連線型別，斷開連線會移除 Hubitos 持有的相關憑據，或透過整合服務商請求斷開。移除本機持有的憑據不一定等同於在平台端撤銷授權；您也可以在平台設定中撤銷存取權限。此前儲存的內容及後設資料的刪除另見下文。

桌面權限與本機資訊

桌面應用會儲存本機執行所需的資訊，例如登入會話資訊、偏好、快取和本機工作檔案。本機處理不意味著所有功能均可離線執行：使用雲端 AI、同步、上傳或已連線服務時，會將相應操作所需的資訊傳送給 Hubitos 或相關服務提供商。

當劃詞功能處於啟用狀態且作業系統允許存取時，Hubitos 可以檢測選中的文字及其來源應用。根據作業系統和應用的不同，選中文字檢測可能使用輔助功能介面或複製到剪貼簿的備用方式。呼叫 AI 操作可能將選中文字傳送至已配置的 AI 服務；儲存至雲端檔案會上傳選中的內容。您可以在設定中管理該功能及可用的應用篩選設定，並撤銷作業系統權限。

當您發起截圖時，Hubitos 使用螢幕捕獲權限獲取您所選區域需要的影象。提交到對話或儲存到雲端儲存的截圖，會像其他上傳內容一樣處理。如果您啟用本機任務執行，任務相關的檔案、命令和執行結果可能由桌面執行環境處理並返回服務端。繼續操作前，請審閱請求的存取權限和可用的審批控制。

使用分析、Cookie 及類似儲存

Hubitos 使用本機儲存、會話儲存、應用檔案，以及在服務元件使用時的 Cookie，維持會話、偏好和服務功能。清除本機資料可能使您登出或重置偏好，但不會刪除我們伺服器上儲存的資料。

啟用產品分析時，Hubitos 使用 PostHog 接收功能事件、路由資訊、匿名標識和會話標識、已登入時的 Hubitos 使用者標識、語言、作業系統和使用者代理資訊、應用版本、發布渠道、事件時間及經脫敏的錯誤診斷資訊。這些標識可能使事件與帳號關聯；這並不表示所有分析均為匿名。

客戶端分析配置禁用了會話錄製和自動互動採集，並過濾提示詞、訊息文字、選中文字、電子郵件地址、憑據及本機檔案路徑等敏感事件屬性。這描述的是分析資料的處理方式，而非提供 AI 或發布功能所需的內容處理。網路服務也可能處理 IP 地址和技術請求資訊，以提供和保護服務。

如果適用法律要求對非必要跟蹤取得同意或提供退出選項，我們將提供並尊重該選擇。有關分析的隱私請求，可聯絡 support@hubitos.ai。

保留與保護

我們僅在實現本政策所述目的所必需的期間保留個人資訊，並考慮您對服務的使用、刪除請求、資訊型別、適用法律和平台要求。我們採用存取控制及其他合理的技術和組織措施保護資訊。任何系統都無法保證絕對安全。

保留例外僅限於為特定法律、計費、安全或爭議處理目的而確有必要的資訊。備份副本可能保留至其按照適用保留流程到期。資料刪除說明介紹了如何申請刪除及必要保留的相關資訊。

使用者如何撤銷授權

使用者始終掌控已連線的帳號。

  • 在提供相應功能的情況下，使用者可在 Hubitos 的帳號授權或設定頁面中斷開服務商連線。
  • 使用者也可透過相關 Meta、Facebook、Instagram 或 Threads 帳號中有關已連線應用和網站的設定，撤銷 Hubitos 的存取權限。

對於 TikTok、YouTube、X、LinkedIn 及其他整合，您也可使用平台的已連線應用管理功能。如果連線由 Upload-Post 提供，平台顯示的應用名稱可能不是 Hubitos；請核對您實際授予的授權。撤銷存取權限時，請停止或取消待執行的工作流。僅斷開連線可能無法撤回已提交給平台的操作。

使用者如何刪除資料

使用者可請求刪除與其 Hubitos 帳號或已連線社交授權有關的個人資料。

  • 請向下方支援郵箱傳送刪除請求，並提供 Hubitos 帳號郵箱及所連線的服務商，以便定位資料。
  • Hubitos 會在合理期限內處理經驗證的刪除請求，並在處理完成時予以確認。
  • 出於安全、防範欺詐、合規、計費記錄或備份完整性的必要，部分資訊可能被保留。

請求詳情、身份驗證、服務商處理、保留資料，以及刪除 Hubitos 記錄與刪除社交平台內容之間的區別，請參閱獨立的資料刪除說明。如平台規定更短的刪除期限，該要求適用於相關平台資料。
