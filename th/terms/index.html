รับ Hubitos

ข้อกำหนดการให้บริการของ Hubitos

ข้อกำหนดเหล่านี้ควบคุมการเข้าถึงและการใช้งานเว็บไซต์ Hubitos แอปพลิเคชันเดสก์ท็อป ซอฟต์แวร์ เครื่องมือ AI การผสานรวม และบริการที่เกี่ยวข้อง การเข้าถึงหรือใช้ Hubitos แสดงว่าคุณยอมรับข้อกำหนดเหล่านี้

Hubitos ดำเนินการโดยผู้ให้บริการซอฟต์แวร์อิสระ หากคุณไม่เห็นด้วยกับข้อกำหนดเหล่านี้ โปรดอย่าใช้บริการ

1. บริการของเรา

Hubitos มอบเลเยอร์ปฏิบัติการที่ขับเคลื่อนโดย AI สำหรับการทำงาน ระบบอัตโนมัติ และการสร้างเนื้อหา บริการอาจรวมถึง: ขึ้นอยู่กับการกำหนดค่าของคุณ

  • ผู้ช่วย AI และเครื่องมือที่ขับเคลื่อนด้วย AI
  • การสร้างเนื้อหา การแก้ไข และการนำเนื้อหาไปใช้ใหม่
  • เวิร์กโฟลว์อัตโนมัติและการดำเนินงาน
  • ฐานความรู้และเครื่องมือที่เกี่ยวข้องกับไฟล์
  • การเชื่อมต่อกับแอปพลิเคชัน บริการ และอุปกรณ์ผู้ใช้
  • แอปพลิเคชันเดสก์ท็อปสำหรับระบบปฏิบัติการที่รองรับ
  • การจัดการและการเผยแพร่เนื้อหาโซเชียลมีเดีย
  • การเชื่อมต่อบัญชี TikTok การวิเคราะห์เนื้อหา และคุณสมบัติการเผยแพร่
  • ความสามารถในการประมวลผลแบบโลคัล คลาวด์ คลาวด์ส่วนตัว หรือแบบไฮบริด

คุณสมบัติบางอย่างอาจใช้ได้เฉพาะในบางภูมิภาค แพ็กเกจ แอปพลิเคชัน หรือสภาพแวดล้อมเท่านั้น

รายการข้างต้นอธิบายความสามารถในการให้บริการที่เป็นไปได้ ไม่ใช่การรับรองว่าทุกฟีเจอร์ โหมดการใช้งาน หรือการบูรณาการสามารถใช้งานได้กับผู้ใช้ทุกคน คุณสมบัติที่แสดงเฉพาะในสภาพแวดล้อมการแสดงตัวอย่างหรือการทดสอบไม่รับประกันคุณสมบัติการใช้งานจริง

Hubitos ให้บริการผู้ใช้ทั่วเอเชียตะวันออกเฉียงใต้ รวมถึงเวียดนาม มาเลเซีย สิงคโปร์ และอินโดนีเซีย ขึ้นอยู่กับความพร้อมในการให้บริการและกฎหมายที่บังคับใช้ สิทธิ์ท้องถิ่นที่บังคับยังคงใช้อยู่

2. คุณสมบัติและบัญชี

คุณต้องมีความสามารถตามกฎหมายในการทำข้อตกลงเหล่านี้เพื่อใช้ Hubitos หากคุณอายุต่ำกว่าที่กฎหมายกำหนดในเขตอำนาจศาลของคุณ คุณสามารถใช้บริการได้เฉพาะเมื่อต้องมีส่วนร่วมและได้รับความยินยอมจากพ่อแม่หรือผู้ปกครองตามกฎหมายตามที่กฎหมายกำหนด คุณตกลงที่จะให้ข้อมูลที่ถูกต้องและเป็นปัจจุบันเมื่อสร้างหรือใช้บัญชี คุณมีหน้าที่รับผิดชอบสำหรับ:

  • การรักษาความปลอดภัยให้กับบัญชีของคุณ
  • การรักษาข้อมูลการเข้าสู่ระบบของคุณเป็นความลับ
  • กิจกรรมทั้งหมดที่ดำเนินการผ่านบัญชีของคุณ
  • แจ้งให้เราทราบทันทีเมื่อมีการเข้าถึงโดยไม่ได้รับอนุญาต

คุณต้องไม่เปิดเผยข้อมูลประจำตัวบัญชีของคุณ โทเค็นการเข้าถึง คีย์ API หรือรหัสอนุญาตกับผู้อื่น

3. คุณสมบัติ AI และผลลัพธ์ที่สร้างขึ้น

Hubitos อาจใช้ปัญญาประดิษฐ์เพื่อสร้างข้อความ รูปภาพ แผน คำแนะนำ สรุป การจำแนกประเภท ขั้นตอนการทำงาน และเอาต์พุตอื่นๆ ("เอาต์พุต AI") เอาต์พุต AI อาจไม่สมบูรณ์ ไม่ถูกต้อง ลำเอียง หรือไม่เหมาะสมสำหรับวัตถุประสงค์เฉพาะของคุณ คุณมีหน้าที่รับผิดชอบในการตรวจสอบและตรวจสอบเอาต์พุต AI ก่อนที่จะใช้ เผยแพร่ หรือไว้วางใจ Hubitos ไม่รับประกันว่าเอาท์พุตของ AI จะเป็น:

  • ถูกต้องหรือครบถ้วน
  • ต้นฉบับหรือฟรีจากสิทธิ์ของบุคคลที่สาม
  • เหมาะสำหรับธุรกิจเฉพาะ กฎหมาย การแพทย์ การเงิน หรือวัตถุประสงค์ทางวิชาชีพ
  • ยอมรับโดย TikTok หรือแพลตฟอร์มบุคคลที่สามอื่น ๆ
  • ใช้งานได้โดยไม่มีการหยุดชะงักหรือข้อผิดพลาด

คุณมีหน้าที่รับผิดชอบในการขอคำแนะนำจากผู้เชี่ยวชาญที่จำเป็นสำหรับสถานการณ์เฉพาะของคุณ

4. เนื้อหาของผู้ใช้

คุณยังคงเป็นเจ้าของข้อความ ไฟล์ รูปภาพ วิดีโอ ข้อมูล คำแนะนำ และเนื้อหาอื่น ๆ ที่คุณส่งหรือประมวลผลผ่าน Hubitos ("เนื้อหาของผู้ใช้") คุณให้สิทธิ์ Hubitos แบบจำกัดและไม่ผูกขาดทั่วโลกในการโฮสต์ ส่ง ประมวลผล ทำซ้ำ แก้ไขในกรณีที่จำเป็นทางเทคนิค วิเคราะห์และแสดงเนื้อหาผู้ใช้ของคุณเท่าที่จำเป็นเพื่อให้บริการและดำเนินการบริการ ดำเนินการที่คุณร้องขอ สร้างเอาต์พุต AI รักษาความปลอดภัยและความน่าเชื่อถือ แก้ไขปัญหาและสนับสนุนบริการ และปฏิบัติตามภาระผูกพันทางกฎหมาย คุณรับรองและรับประกันว่า:

  • คุณเป็นเจ้าของหรือมีสิทธิ์ที่จำเป็นในการใช้เนื้อหาผู้ใช้ของคุณ
  • เนื้อหาผู้ใช้ของคุณไม่ละเมิดกฎหมายที่บังคับใช้
  • เนื้อหาผู้ใช้ของคุณไม่ละเมิดทรัพย์สินทางปัญญา ความเป็นส่วนตัว การเผยแพร่ หรือสิทธิ์อื่น ๆ ของบุคคลอื่น
  • คุณได้รับอนุญาตที่จำเป็นทั้งหมดจากบุคคลที่ปรากฏในเนื้อหาของคุณ
  • คุณจะไม่ใช้ Hubitos เพื่อประมวลผลหรือเผยแพร่เนื้อหาโดยไม่ได้รับอนุญาตที่เหมาะสม

ใบอนุญาตนี้ไม่ได้ถ่ายโอนความเป็นเจ้าของเนื้อหาผู้ใช้ของคุณไปยัง Hubitos หรือให้สิทธิ์ที่ไม่ จำกัด ในการใช้เนื้อหาสำหรับการโฆษณาหรือการฝึกอบรมโมเดลที่ไม่เกี่ยวข้อง สิทธิ์ในเอาท์พุต AI ขึ้นอยู่กับกฎหมายที่บังคับใช้และข้อกำหนดของบุคคลที่สามที่เกี่ยวข้อง เอาต์พุตที่สร้างขึ้นอาจคล้ายกับเอาต์พุตของผู้ใช้รายอื่น การใช้รูปลักษณ์ เสียง แบรนด์ รูปภาพผลิตภัณฑ์ หรือสื่อที่ได้รับการคุ้มครองอื่นๆ ของบุคคลนั้น จำเป็นต้องได้รับสิทธิ์และการอนุญาตที่เกี่ยวข้องกับการใช้งานนั้น

5. แอปพลิเคชันที่เชื่อมต่อและบริการของบุคคลที่สาม

Hubitos อาจอนุญาตให้คุณเชื่อมต่อแอปพลิเคชัน แพลตฟอร์ม บัญชี อุปกรณ์ หรือบริการของบุคคลที่สาม เมื่อคุณเชื่อมต่อบริการของบุคคลที่สาม:

  • คุณอนุญาตให้ Hubitos เข้าถึงข้อมูลและการอนุญาตที่คุณเลือก
  • คุณยังคงรับผิดชอบในการปฏิบัติตามข้อกำหนดและนโยบายของบุคคลที่สามนั้น
  • บุคคลที่สามอาจเปลี่ยนแปลง จำกัด ระงับหรือยุติการให้บริการหรือ API
  • Hubitos ไม่ได้ควบคุมความพร้อมใช้งาน ความแม่นยำ ความปลอดภัย หรือประสิทธิภาพของบริการของบุคคลที่สาม

คุณสามารถเพิกถอนการบูรณาการผ่าน Hubitos หรือบริการของบุคคลที่สามที่เกี่ยวข้องได้ การเพิกถอนการเข้าถึงอาจไม่ลบข้อมูลที่ประมวลผลหรือจัดเก็บโดย Hubitos ทันที การลบข้อมูลได้รับการจัดการตามนโยบายความเป็นส่วนตัวของเรา

การบูรณาการบางอย่างมีให้ผ่านตัวกลาง ในการออกแบบการเชื่อมต่อบนโซเชียลในปัจจุบัน Upload-Postสนับสนุนการเชื่อมต่อสำหรับเพจ Instagram, Facebook, TikTok, YouTube, Threads และ LinkedIn; X ใช้ขั้นตอนการอนุญาตแยกต่างหาก สิทธิ์เฉพาะและข้อมูลประจำตัวของแอปพลิเคชันจะแสดงขึ้นในระหว่างการอนุญาต ประกาศการอนุญาตแพลตฟอร์มของบุคคลที่สามจะอธิบายประเภทการเชื่อมต่อเหล่านี้

หากคุณใช้คุณสมบัติ Hubitos ที่ใช้บริการ YouTube API แสดงว่าคุณยอมรับที่จะผูกพันตามข้อกำหนดการให้บริการของ YouTube การประมวลผลของ Google อธิบายไว้ในนโยบายความเป็นส่วนตัวของ Google

6. บูรณาการ TikTok

Hubitos อาจเชื่อมต่อกับ TikTok ผ่านผลิตภัณฑ์สำหรับนักพัฒนาอย่างเป็นทางการของ TikTok ซึ่งรวมถึง Login Kit, Display API และ Content Posting API เมื่อคุณเชื่อมต่อบัญชี TikTok:

  • คุณอนุญาตให้ Hubitos เข้าถึงเฉพาะข้อมูลและการอนุญาตที่คุณอนุมัติ
  • Hubitos อาจเข้าถึงข้อมูลโปรไฟล์ที่ได้รับอนุญาต สถิติ และวิดีโอสาธารณะ
  • Hubitos อาจวิเคราะห์เนื้อหา TikTok ที่ได้รับอนุญาตเพื่อให้มีคุณสมบัติต่างๆ
  • Hubitos อาจเผยแพร่เนื้อหาไปยัง TikTok หลังจากที่คุณอนุญาตการดำเนินการเผยแพร่ที่เกี่ยวข้อง
  • คุณยังคงรับผิดชอบต่อเนื้อหา คำอธิบายภาพ แฮชแท็ก ผู้ชม และการตั้งค่าความเป็นส่วนตัวของโพสต์ TikTok ใด ๆ
  • Hubitos ไม่รับประกันว่า TikTok จะยอมรับ เผยแพร่ แนะนำ หรือดูแลรักษาเนื้อหาของคุณ
  • TikTok อาจตรวจสอบ จำกัด ลบหรือจำกัดการเปิดเผยเนื้อหาที่เผยแพร่

การใช้ TikTok ของคุณยังอยู่ภายใต้ข้อกำหนดการให้บริการ นโยบายความเป็นส่วนตัว หลักเกณฑ์ของชุมชน และนโยบาย TikTok อื่นๆ ที่เกี่ยวข้องของ TikTok Hubitos เป็นบริการอิสระของบุคคลที่สาม และไม่ได้เป็นเจ้าของ สนับสนุน รับรอง หรือดำเนินการโดย TikTok

การอ้างอิงถึงผลิตภัณฑ์ของนักพัฒนา TikTok ข้างต้นไม่ได้หมายความว่าทุกผลิตภัณฑ์ได้รับการเปิดใช้งานหรือได้รับการอนุมัติอย่างอิสระสำหรับ Hubitos ในทุกสภาพแวดล้อม การเชื่อมต่อ TikTok อาจถูกส่งผ่านผู้ให้บริการบูรณาการของเรา เฉพาะฟังก์ชันการทำงานที่คุณสามารถใช้ได้และการอนุญาตที่คุณอนุมัติเท่านั้นที่จะนำไปใช้

ในกรณีที่ TikTok ต้องการการตรวจสอบหรือการยืนยันที่ชัดเจนสำหรับการดำเนินการเผยแพร่ ข้อกำหนดนั้นจะมีผลใช้แม้ว่าคุณจะได้อนุญาตเวิร์กโฟลว์ไว้ก่อนหน้านี้แล้วก็ตาม คุณต้องจัดเตรียมเนื้อหาเชิงพาณิชย์ สื่อสังเคราะห์ หรือการเปิดเผยอื่น ๆ ที่จำเป็นอย่างถูกต้อง การอนุญาตผู้ขาย TikTok Shop แยกจากการเผยแพร่ทางโซเชียลของ TikTok การเชื่อมต่ออันหนึ่งไม่ได้รับอนุญาตอีกอันหนึ่ง

7. การเผยแพร่เนื้อหา

หากคุณใช้ Hubitos เพื่อเผยแพร่เนื้อหาไปยังแพลตฟอร์มที่เชื่อมต่อ:

  • คุณต้องมีสิทธิ์และการอนุญาตที่จำเป็นสำหรับเนื้อหา
  • คุณต้องตรวจสอบเนื้อหาและการตั้งค่าการเผยแพร่ก่อนที่จะส่ง
  • คุณต้องไม่ใช้คุณลักษณะการเผยแพร่สำหรับสแปม การหลอกลวง การคุกคาม หรือกิจกรรมที่ผิดกฎหมาย
  • คุณต้องปฏิบัติตามกฎของแพลตฟอร์มปลายทาง
  • Hubitos จะไม่รับผิดชอบต่อเนื้อหาที่ถูกลบ จำกัด ล่าช้าหรือปฏิเสธโดยแพลตฟอร์มบุคคลที่สาม

Hubitos จะเริ่มการดำเนินการเผยแพร่เมื่อมีการร้องขอหรือยืนยันผ่านบริการเท่านั้น

โพสต์ตามกำหนดการที่ได้รับอนุมัติหรือระบบอัตโนมัติที่เปิดใช้งานอาจทำงานในภายหลังโดยที่อุปกรณ์ของคุณเปิดอยู่ ซึ่งฟีเจอร์ดังกล่าวรองรับ ตรวจสอบบัญชีปลายทาง สื่อ คำอธิบาย เขตเวลา กำหนดการ และการตั้งค่าแพลตฟอร์มที่เกี่ยวข้องก่อนที่จะอนุมัติ คุณมีหน้าที่รับผิดชอบในการอัปเดตหรือยกเลิกการกระทำในอนาคตที่คุณไม่ต้องการอีกต่อไป การดำเนินการที่ส่งมาอาจกำลังดำเนินการกับบุคคลที่สามอยู่แล้วและไม่สามารถเรียกคืนได้เสมอไป

  • ทบทวนการดำเนินการก่อนอนุญาต
  • รักษาการเข้าถึงอินเทอร์เน็ตที่เชื่อถือได้เมื่อจำเป็น
  • ตรวจสอบให้แน่ใจว่าคุณมีสิทธิ์ในการเข้าถึงและประมวลผลไฟล์บนอุปกรณ์ของคุณ

คุณต้องไม่ใช้ Hubitos เพื่อเข้าถึง แก้ไข หรือดำเนินการใดๆ บนอุปกรณ์หรือระบบโดยไม่ได้รับอนุญาตอย่างเหมาะสม

คุณสมบัติเดสก์ท็อปอาจอ่านข้อความที่เลือก ใช้ทางเลือกคลิปบอร์ด จับภาพหน้าจอที่คุณเริ่มต้น เข้าถึงไฟล์ที่เกี่ยวข้องกับงาน หรือใช้เครื่องมือในเครื่อง ทั้งนี้ขึ้นอยู่กับการตั้งค่าและการอนุญาตระบบปฏิบัติการของคุณ การเรียกใช้ Cloud AI หรือการซิงโครไนซ์สามารถส่งเนื้อหาที่เกี่ยวข้องและผลการดำเนินการออกจากอุปกรณ์ของคุณได้ จัดการการตั้งค่าคุณสมบัติและการอนุญาตระบบปฏิบัติการตามความต้องการของคุณ การลบแอปพลิเคชันหรือการออกจากระบบไม่ได้เป็นการลบบัญชีคลาวด์หรือเนื้อหาบนคลาวด์ของคุณ

  • แทรกแซงการทำงานหรือความปลอดภัยของ Hubitos หรือบริการของบุคคลที่สาม

10. การชำระเงินและการสมัครสมาชิก

คุณสมบัติบางอย่างของ Hubitos อาจต้องมีการชำระเงิน เครดิต หรือสมัครสมาชิก ในกรณีที่เกี่ยวข้อง:

  • คุณอนุญาตให้ผู้ให้บริการชำระเงินที่เกี่ยวข้องเรียกเก็บเงินจากวิธีการชำระเงินที่คุณเลือก

เราอาจระงับหรือยุติการเข้าถึง Hubitos ของคุณหาก:

  • คุณละเมิดข้อกำหนดเหล่านี้
  • คุณใช้บริการในทางที่ผิด;
  • การใช้งานของคุณก่อให้เกิดความเสี่ยงด้านความปลอดภัย กฎหมาย หรือการปฏิบัติงาน
  • เราจำเป็นต้องดำเนินการดังกล่าวตามกฎหมายหรือแพลตฟอร์มของบุคคลที่สาม
  • คุณไม่สามารถชำระค่าธรรมเนียมที่เกี่ยวข้องได้

คุณสามารถหยุดใช้ Hubitos ได้ตลอดเวลา หลังจากการยุติ ข้อกำหนดที่เกี่ยวข้องกับทรัพย์สินทางปัญญา เนื้อหาของผู้ใช้ การปฏิเสธความรับผิดชอบ การจำกัดความรับผิด การชดใช้ค่าเสียหาย และการระงับข้อพิพาท จะยังคงมีผลบังคับใช้

คุณสามารถขอปิดและลบบัญชีได้ที่ support@hubitos.ai. คำแนะนำการลบข้อมูลจะอธิบายขอบเขต การตรวจสอบ ระยะเวลา และข้อยกเว้นในการเก็บรักษาที่จำกัด ใบอนุญาตเนื้อหาจะคงอยู่ได้เฉพาะในขอบเขตที่จำเป็นสำหรับวัตถุประสงค์ที่จำกัดและการเก็บรักษาตามกฎหมายที่อธิบายไว้ในข้อกำหนดเหล่านี้และนโยบายความเป็นส่วนตัว การยุติไม่ได้สร้างใบอนุญาตทั่วไปตลอดไปในการใช้เนื้อหาของคุณ

18. การเปลี่ยนแปลงข้อกำหนดเหล่านี้

เราอาจปรับปรุงข้อกำหนดเหล่านี้เป็นครั้งคราว เวอร์ชันที่อัปเดตจะถูกโพสต์ในหน้านี้พร้อมกับวันที่ "อัปเดตล่าสุด" ที่แก้ไข การที่คุณใช้งาน Hubitos ต่อไปหลังจากข้อกำหนดที่อัปเดตมีผลบังคับใช้ หมายความว่าคุณยอมรับข้อกำหนดที่แก้ไข

เราจะแจ้งให้ทราบเพิ่มเติมเกี่ยวกับการเปลี่ยนแปลงที่สำคัญหากจำเป็น การใช้งานต่อไปไม่ได้แทนที่ความยินยอมใหม่หรือการยอมรับอย่างชัดแจ้งในกรณีที่กฎหมายที่บังคับใช้กำหนด

19. กฎหมายที่ใช้บังคับ

ข้อกำหนดเหล่านี้อยู่ภายใต้กฎหมายที่บังคับใช้ในสถานที่ที่ Hubitos ดำเนินการ โดยไม่คำนึงถึงหลักการขัดกันของกฎหมาย ข้อพิพาทใดๆ ที่เกิดขึ้นจากข้อกำหนดเหล่านี้หรือการใช้งาน Hubitos ของคุณจะถูกจัดการโดยศาลที่มีเขตอำนาจศาลที่เหมาะสม เว้นแต่กฎหมายที่บังคับใช้จะกำหนดเป็นอย่างอื่น

ส่วนนี้ไม่ได้ลบการคุ้มครองที่บังคับหรือการเข้าถึงศาลสำหรับผู้บริโภคภายใต้กฎหมายที่บังคับใช้
