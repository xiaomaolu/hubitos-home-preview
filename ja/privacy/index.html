収集するデータ

Hubitosは、ワークスペースと接続先への投稿ワークフローの運営に必要な情報のみを収集します。

  • 氏名、メールアドレス、ユーザー識別子、ワークスペースの設定などのアカウント情報。
  • プロンプト、投稿の下書き、キャプション、アップロードした添付ファイル、生成ファイル、ワークフローの設定など、お客様が提供するコンテンツ。
  • プロバイダー名、付与されたスコープ、接続済みアカウント識別子、トークンの状態など、接続先サービスのアクセス許可に関するメタデータ。
  • 機能イベント、エラーログ、デバイス・ブラウザー情報、アプリのバージョンなど、基本的な利用状況と診断情報。

利用する機能に応じて、これらの区分には以下も含まれます。

  • メールアドレスや電話番号、パスワード認証の記録、検証イベント、ログインセッション、ログイン用プロバイダーが返す識別子など、ログインとアカウントの安全性に関する情報。Googleなどのプロバイダーでログインしても、それだけでSNSへの投稿や無関係なアカウントデータへのアクセスが許可されることはありません。
  • アカウント・チャンネル識別子、表示名、プロフィール画像、Facebook Pages、付与された権限、接続状態、投稿、投稿処理の受領記録、許可されたエンゲージメント・パフォーマンス情報など、接続済みSNSアカウントの情報。
  • 会話、ファイル、画像、動画、商品参考資料、SNS分析の入力、下書き・予約投稿、作業結果などのコンテンツと作業の背景情報。利用可能かつ有効な場合は、その後の作業を個別化するための、保存済みAIメモリや設定も含まれます。
  • プラン、クレジット残高、利用状況、注文・決済の参照情報、決済状態、サブスクリプションの状態など、請求と取引の情報。決済カード情報は、決済事業者の画面を通じて同事業者が取り扱います。Hubitosは、購入を管理するために必要な取引情報を受け取ります。
  • 連携済みメッセージボットを通じて、お客様が意図的に送信する情報。連携アカウントの識別子、メッセージ、添付ファイル、配信情報を含みます。ボットを接続しても、非公開の会話すべてに一般的なアクセス権が与えられるわけではありません。
  • お客様から分析を依頼された公開アカウント、投稿、商品ページの情報。該当するプラットフォームまたはデータ取得サービスから取得します。公開情報の分析と非公開アカウントへのアクセス許可は別の処理であり、いずれも非公開のプラットフォームデータへの無制限のアクセスを認めるものではありません。

データを収集する目的

データは、Hubitosの機能提供、利用者のセッション保護、およびサポートに使用します。

  • 会話、ワークフロー、ツールキット、生成ファイル、利用者の設定を作成・保存し、再度開き、同期するため。
  • 利用者の指示や添付ファイルを処理し、AIアシスタントが依頼された作業の下書き、要約、変換、整理を行えるようにするため。
  • 利用者の認証、不適切な利用の防止、エラーの調査、信頼できるサービス動作の維持のため。
  • サポート依頼への対応、報告された問題の調査、重要な製品・ポリシーの更新のご案内のため。

Threads、Facebook、Instagramのアクセス許可データの利用方法

利用者がMetaのサービスを接続した場合、Hubitosは、利用者が指示したワークスペースや投稿の操作にのみ、付与された権限を使用します。

  • Hubitosは、接続アカウントの識別、利用者が承認したコンテンツの準備・投稿など、利用者が選択した機能に必要な権限のみを要求します。
  • アクセス許可データは、接続アカウントの状態表示、コンテンツの下書き・公開、許可された投稿メタデータの読み取り、および依頼されたワークフローの接続維持に使用する場合があります。
  • Hubitosは、Metaのアクセス許可データを販売しません。製品の運営に必要なサービス提供者、または法令で求められる場合を除き、第三者と共有しません。

TikTokのアクセス許可データとコンテンツデータの利用方法

提供される場合、Hubitosは、Login Kit、Display API、Content Posting APIなどTikTokの開発者向け製品を利用し、直接または接続を支援するサービス提供者を通じて、TikTokアカウントの接続、コンテンツ分析、投稿に対応する場合があります。利用できる製品と権限は、実際に有効な連携と、お客様が承認した許可画面の内容によって決まります。

  • 承認済みのプロフィール情報、アカウント識別子、統計、動画を使用して接続アカウントを識別し、お客様が依頼した分析、コンテンツ管理、投稿機能を提供します。
  • 承認済みの予約操作を含め、お客様が依頼または確認した投稿操作に限り、コンテンツをTikTokへ送信します。コンテンツ、および当該操作で表示される視聴者、プライバシー、交流、情報開示の設定は、お客様が管理します。
  • アカウントの接続は、任意のコンテンツの公開、非公開メッセージへのアクセス、無関係なTikTokデータの利用を許可するものではありません。
  • TikTokは、自身の規約とプライバシーポリシーに基づき、送信されたコンテンツと関連メタデータを処理する場合があります。Hubitosとの接続を解除しても、TikTokがすでに保持する動画や投稿は削除されません。
  • Hubitosの利用可能な接続管理機能、またはTikTokの連携アプリ設定から許可を取り消せます。Hubitosが保持するデータの削除は、support@hubitos.aiに依頼できます。

TikTok Shopは、独立した販売者向けアクセス許可です。提供され、かつ接続した場合、個別に有効なショップ機能に必要なショップ識別子、ショップ情報、許可スコープ、認証情報を取得する場合があります。TikTokのSNSアカウントを接続しても、TikTok Shopへのアクセスは許可されません。追加の商品・注文・顧客データの処理は、利用に先立ち、該当するショップ機能で開示する必要があります。

GoogleとYouTubeのデータ

YouTube接続を利用する場合、Hubitosは、投稿連携プロバイダーを通じた利用を含め、YouTube API Servicesを使用し、お客様が許可したチャンネルと投稿操作を管理します。関連情報には、チャンネル識別子、プロフィール情報、アップロードのメタデータ、投稿状態、および許可されたパフォーマンス情報が含まれる場合があります。

GoogleでのログインとYouTubeチャンネルへのアクセス許可は、目的が異なります。いずれも、別の機能がアクセスを要求し、お客様が許可しない限り、Gmail、Google Drive、その他のGoogle製品へのアクセスを認めるものではありません。

HubitosによるGoogle APIから受け取った情報の利用と移転は、Limited Use（限定的な使用）の要件を含むGoogle API Services User Data Policyに従います。この情報は、開示された利用者向け機能に使用し、広告ターゲティングや汎用AIモデルの開発・学習には使用しません。許可されるAI処理も、許可された機能と適用されるプラットフォーム要件の範囲に限られます。

Googleによる処理には、Googleプライバシーポリシーも適用されます。アクセス許可は、Googleのセキュリティ設定から取り消せます。Hubitosへの削除依頼の方法は、以下およびデータ削除の手順に記載しています。

アクセストークンの取り扱い

アクセストークンは、機密性の高い認証情報として取り扱います。

  • Hubitosがアクセストークンを保存するのは、利用者が許可した接続の維持、または依頼されたワークフローの実行に必要な場合に限ります。
  • 保存されたトークンは、合理的な技術的管理策によって保護し、公開ページ、利用者向けログ、マーケティング資料には表示しません。
  • トークンは、許可された接続や依頼された操作に必要な間のみ保持します。接続解除時には、接続の種類に応じて、Hubitosが保持する該当の認証情報を削除するか、連携プロバイダーを通じて接続解除を依頼します。ローカルに保持する認証情報の削除は、必ずしもプラットフォーム側で許可を取り消すことと同じではありません。プラットフォームの設定からも許可を取り消せます。保存済みコンテンツとメタデータの削除については、以下で別途説明します。

デスクトップの権限とローカル情報

デスクトップアプリは、ログインセッション、設定、キャッシュ、作業用のローカルファイルなど、デバイス上での動作に必要な情報を保存します。ローカル処理であっても、すべての機能がオフラインで動作するわけではありません。クラウドAI、同期、アップロード、接続先サービスを使用すると、その操作に必要な情報がHubitosまたは該当するサービス提供者に送信されます。

テキスト選択機能が有効で、OSがアクセスを許可している場合、Hubitosは選択したテキストと元のアプリを検出できます。OSやアプリに応じて、アクセシビリティの仕組み、または代替手段としてクリップボードへのコピーを使用する場合があります。AI操作を実行すると、選択したテキストが設定済みのAIサービスに送信される場合があります。クラウドファイルに保存すると、その内容がアップロードされます。設定で機能や利用可能なアプリのフィルターを管理し、OSの権限を取り消せます。

お客様が画面キャプチャを開始すると、Hubitosは画面キャプチャのアクセス権限を使い、選択に必要な画像を取得します。会話に送信した画像やクラウドに保存した画像は、他のアップロード済みコンテンツと同様に処理します。ローカルでのタスク実行を有効にした場合、関連するファイル、コマンド、実行結果をデスクトップの実行環境が処理し、本サービスへ返す場合があります。実行前に、要求されたアクセスと承認の設定を確認してください。

利用状況分析、Cookie、類似の保存技術

Hubitosは、セッション、設定、サービス機能の維持のため、ローカルストレージ、セッションストレージ、アプリのファイル、およびサービスの構成要素が使用する場合はCookieを利用します。ローカルデータを消去すると、ログアウトや設定のリセットが行われる場合がありますが、サーバーに保存されたデータは削除されません。

製品の利用状況分析が有効な場合、HubitosはPostHogを使用し、機能イベント、経路情報、匿名識別子・セッション識別子、ログイン時のHubitosユーザー識別子、言語、OS・ユーザーエージェント情報、アプリのバージョン、リリースチャンネル、イベントの時刻、機密情報を除去したエラー診断情報を受け取ります。これらの識別子によって、イベントをアカウントに関連付けられる場合があります。すべての利用状況分析が匿名であるという意味ではありません。

クライアントの利用状況分析設定では、セッション録画と操作の自動収集を無効にしています。プロンプト、メッセージ本文、選択したテキスト、メールアドレス、認証情報、ローカルファイルのパスなど、機密性の高いイベント属性を除外します。これは利用状況分析の取り扱いの説明であり、AI機能や投稿機能の提供に必要なコンテンツ処理の説明ではありません。ネットワークサービスでは、サービスの提供と保護のため、IPアドレスや技術的なリクエスト情報も処理する場合があります。

適用法令が、必須でない追跡について同意やオプトアウトを求める場合、当社はその選択肢を提供し、選択を尊重します。利用状況分析に関するプライバシーのご依頼は、support@hubitos.aiにお寄せください。

情報の保持と保護

項目の削除、ローカルデータの消去、メモリ機能の停止、プラットフォームの接続解除だけでは、関連情報がすべて削除されるとは限りません。関連するアカウントデータすべて、または特定の情報区分の削除を希望する場合は、support@hubitos.aiへご依頼ください。依頼の範囲内で、関連するコンテンツと保持済みの複製を確認します。

保持の例外は、特定の法律、請求、安全性、紛争対応の目的に真に必要な情報に限ります。バックアップは、適用される保持手続きに従って期限が到来するまで残る場合があります。削除依頼の方法と必要な保持については、データ削除の手順をご覧ください。

アクセス許可を取り消す方法

接続済みアカウントは、引き続き利用者が管理できます。

  • 利用可能な場合、Hubitosのアカウント許可画面や設定から、プロバイダーとの接続を解除できます。
  • Meta、Facebook、Instagram、Threadsの該当アカウントにある、連携アプリ・ウェブサイトの設定からも、Hubitosのアクセス許可を取り消せます。

TikTok、YouTube、X、LinkedInなどの連携では、各プラットフォームの連携アプリ管理機能も利用できます。Upload-Postを通じた接続では、表示されるアプリ名がHubitosと異なる場合があります。実際に付与した許可を確認してください。許可を取り消す際は、未実行のワークフローを停止または取り消してください。プラットフォームに送信済みの操作は、接続解除だけでは撤回できない場合があります。

データの削除方法

Hubitosアカウントや、接続済みSNSのアクセス許可に関連する個人データの削除を依頼できます。

  • 以下のサポートメール宛てに、データの特定に必要なHubitosアカウントのメールアドレスと接続先プロバイダーを添えて、削除をご依頼ください。
  • Hubitosは、確認済みの削除依頼に合理的な期間内で対応し、完了した際にその旨をお知らせします。
  • 安全性、不正防止、法令遵守、請求記録、バックアップの完全性のために必要な場合、一部の情報を保持する場合があります。

依頼内容、本人確認、プロバイダーでの対応、保持する情報、およびHubitos内の記録削除とSNS上のコンテンツ削除の違いについては、データ削除の手順をご覧ください。プラットフォームがこれより短い削除期限を定める場合、その要件が該当するプラットフォームデータに適用されます。
